PyORCHESTRA
==============

An example project built with [pybind11](https://github.com/pybind/pybind11).
This requires Python 3.7+; for older versions of Python, check the commit
history.

Installation
------------
To install the ORCHESTRA C++ extension, the presence of a C++ compiler on your
machine is required. 
The C++ compiler comes with Microsoft Visual Studio, or can be installed separately 
according to this description:

https://github.com/bycloudai/InstallVSBuildToolsWindows

When a C++ compiler is present PyORCHESTRA can be installed from source code by: 
 - cloning this repository
 - the commmand `pip install .` from the main directory
 - The test folder contains an example python file and input files
 - This test folder also contains the java version (orchestra2026.jar) than can be used 
 to compare with C++ version, and to interactively create chemical input files.
